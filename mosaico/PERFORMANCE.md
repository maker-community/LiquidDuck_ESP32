# ESP-Mosaico 性能优化记录

设备：ESP-Mosaico V1.2 / ESP32-S31，MicroPixel 0.9.4。

应用内每五秒统计完成帧数及分段耗时。以下为 2026-09-27 真机海洋球模式观测，属于不同时间窗口的实测，未使用固定传感器输入回放。

| 版本 | 完成帧率 | 物理/前处理 | 绘制提交 |
|---|---:|---:|---:|
| 初版（物理栏包含软件绘制） | 7.5–8.5 FPS | 48–50 ms | 49–54 ms |
| 缓存小球纹理、直接绘制 | 15.1 FPS | 28–30 ms | 12–13 ms |
| 压力求解 40→16 次 | 23–24 FPS | 约17 ms | 约13 ms |
| 角色原生纹理旋转与更密的帧调度 | 27–28 FPS | 约17 ms | 8.6–9.2 ms |

保留 240×210 逻辑画布、2倍输出、原粒子数、角色素材和两次物理子步。
压力迭代减少可能使强烈摇动时的流体压缩感略有变化。角色超过256色时仍使用软件旋转备用路径，不同主题和运动状态帧率可能不同。

纹理按主题缓存，角色纹理支持时使用原生 Quad；其它模式也改为直接绘制，不再将完整软件帧重新扫描成水平矩形。

验证：真机启动、画面截图、设备最近错误为空；publish --dry-run 双架构构建与校验通过。尚未公开上架。

## 0.1.1 交互与时间步长调整

保留原粒子数、16 次压力迭代和每帧两个物理子步。使用实际帧间隔（最高50ms，超过100ms的停顿按一帧处理），云朵阻尼、排斥、传感器滤波、角色速度阻尼随时间调整；角色角度弹簧采用轻量小步积分。这减少了帧率变化造成的手感差异，但 FLIP 碰撞仍不保证不同帧率下轨迹完全一致。

曾实测固定30Hz并补算物理的方案，约25.2 FPS，未保留。最终方案海洋球连续窗口约27.7 FPS，物理约16.9–17.0ms，绘制约8.6ms；这是同设备不同时间窗口的观测，未进行固定输入回放，不能视为帧率提升。

增加点击位置水花、底栏当前模式和按压/短暂高亮；旋转云朵按三个圆的完整边界限制，碰撞分离后再次检查边界。缓存渲染器旋转能力查询。

本地 ASan/UBSan 检查触摸取消/多指隔离/越界、不同步长阻尼、72个角度的云朵边界、水花方向及范围。双架构 dry-run 构建通过。未公开发布。

补充观察：切换角色后另有海洋球窗口约24.4–25.3 FPS，绘制耗时增至约14ms，日志显示使用软件矩形绘制路径；该路径的性能限制仍存在。纯色像素模式约29 FPS。设备最近错误返回 null。
